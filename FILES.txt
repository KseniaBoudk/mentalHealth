Kurvan prototype — what each file does
=======================================
(Kurvan = a single-page Swedish mental-health data dashboard, no build step,
opened directly as an HTML file. Written 2026-08-18.)

TOP LEVEL
---------
kurvan.html
    The page itself. Sets the title, loads kurvan.css, defines two empty
    <div>s ("synth" and "app") that JavaScript fills in, then loads all the
    js/ files in order (data -> language -> state -> charts -> views ->
    shell). No <html>/<head>/<body> tags — it's a bare fragment.

kurvan.css
    All styling: colour tokens (light + dark theme), fonts, layout. Colour
    is meaningful throughout the app — teal = survey data, violet =
    register data, oxblood = mortality data.

.gitignore
    Tells git to ignore data/raw/ and data/processed/ (the pipeline's
    intermediate files) and Python cache folders — only the final
    js/data/*.js output is committed.

js/ — THE APP
-------------
js/data/*.js
    Generated data files (not hand-written), one per real source. Hold the
    real, fetched statistics — self-harm hospitalisation, suicide,
    psychiatric care, self-reported anxiety rates, antidepressant/other
    medication dispensing, sickness absence, context layers, BUP waiting
    times, HBSC, and SCB population — pulled from Swedish government
    registers by the pipeline/ scripts. Loaded lazily by js/shell.js after
    the page's first paint (see CLAUDE.md's "Load order"), one small
    <script> at a time instead of one large one. If a given file is empty
    (or hasn't loaded yet), the app falls back to fabricated (fake) numbers
    for that source's indicator(s) instead.

js/real_policy_news.js
    Generated data file holding fetched policy and mental health news items
    and updates.

js/data.js
    The data engine. Defines the fabricated ("synthetic") data generator
    that invents plausible-looking numbers for all 21 Swedish regions, ages,
    and years — used as a fallback and for the two charts that must always
    stay fabricated (their story depends on the fake generator's built-in
    correlations). Also loads/indexes the real data from js/data/*.js
    and decides, per indicator/region/year/age/sex, whether to return a
    real number, a fabricated number, or "no data". Contains the real map
    of Sweden's county borders (as SVG path data) too.

js/lang.js
    All user-facing text, in Swedish and English, as one big lookup table
    (headings, labels, captions, footnotes). Nothing else in the app
    hard-codes displayed text.

js/state.js
    Tiny file holding the app's current state: which language, theme, tab,
    indicator, age group, sex, year, region, and standardisation setting
    are currently selected. Detects the browser's language on first load.

js/charts.js
    Draws all the charts as raw SVG (no charting library): a dot plot (one
    row per region with confidence intervals), a line chart (values over
    age or time), a choropleth map of Sweden's regions, and a scatter plot
    with a regression line.

js/views.js
    Builds each tab's HTML content using the charts and data above: "Läget"
    (overview), "Över tid" (explore/filter, formerly "Utforska"), "Karta"
    (map), "Regioner" (per-region detail), "Metod" (methodology/sources
    table), "Behov & vård" (need vs. healthcare response), "Sjukskrivning"
    (sickness absence, Försäkringskassan F43 data) and "Sammanhang"
    (population density and low-education share alongside the mental-health
    measures, Kolada). All eight sections are built now.

js/shell.js
    Ties everything together: renders the page header/nav/footer around
    whichever tab is active, and wires up all the buttons, dropdowns, and
    map clicks so the app re-renders when the user changes something. This
    is the script that actually starts the app.

pipeline/ — DATA FETCHING (Python, run separately, not part of the live page)
-------------------------------------------------------------------------
pipeline/README.md
    Explains the whole pipeline: which of Kurvan's six indicators now use
    real government data (self-harm, suicide, psychiatric care, severe
    anxiety, sickness absence) versus which is still fabricated
    (antidepressant dispensing, because that source has no queryable API),
    what each real dataset can and can't show (age ranges, sexes, time
    windows), how the Kolada context layers (population density,
    low-education share — not one of the six indicators, backs the
    Sammanhang tab instead) are fetched separately, and how to run every
    fetcher.

pipeline/requirements.txt
    Python dependencies needed to run the fetch scripts (just the
    `requests` HTTP library).

pipeline/manifest.py
    Orchestrator script that runs all pipeline fetchers and data building steps in order.

pipeline/build_kurvan_data.py
    Pipeline script that compiles cleaned raw/processed data into js/data/*.js
    (one small file per source).

pipeline/kommuner.csv
    A reference table mapping Swedish municipality codes to names and
    regions (used to translate API codes to readable names).

pipeline/fetch_socialstyrelsen_mh.py
    Downloads self-harm hospitalisation and suicide rates by region from
    Socialstyrelsen's (the National Board of Health and Welfare) statistics
    API, and saves the raw result to data/raw/socialstyrelsen_mh_raw.json.
    Documents two "silent wrong answer" traps in that API.

pipeline/fetch_socialstyrelsen_psych.py
    Downloads specialist psychiatric care rates by region, age, and sex
    from the same Socialstyrelsen API (a different dataset), saving to
    data/raw/socialstyrelsen_psych_raw.json.

pipeline/fetch_folkhalsodata_hlv.py
    Downloads self-reported "severe anxiety, worry or dread" survey rates
    by region from Folkhälsomyndigheten's (Public Health Agency) HLV
    survey API, saving to data/raw/folkhalsodata_hlv_raw.json. Explains why
    this category was chosen over the dashboard's original one (the
    original stopped being published after 2018).

pipeline/fetch_forsakringskassan.py
    Downloads the share of ongoing sickness-benefit cases with a
    stress-reaction (F43) diagnosis, by county, from Försäkringskassan's
    (the Social Insurance Agency) EntryScape "rowstore" API — a different
    agency and a simpler REST/JSON technology than the three
    Socialstyrelsen/FoHM PxWeb fetchers above. Backs the sjukfranvaro
    indicator; real but only 2005–2019 (the source doesn't extend into the
    2020s). Saves straight to data/processed/forsakringskassan_f43.json,
    no separate raw step.

pipeline/fetch_kolada_context.py
    Downloads population density and low-education share by municipality
    from Kolada (Sweden's municipal/regional KPI database), aggregated up
    to Kurvan's 21 regions as an unweighted mean via kommuner.csv. Backs
    the Sammanhang tab's two context layers — not one of Kurvan's six
    mental-health indicators. Saves straight to
    data/processed/kolada_context.json, no separate raw step.

pipeline/fetch_hbsc.py
    Downloads the share of 11/13/15-year-olds reporting feeling low at
    least weekly from Folkhälsomyndigheten's Skolbarns hälsovanor (HBSC)
    survey — same Folkhälsodata PxWeb host as fetch_folkhalsodata_hlv.py,
    a different table. Backs the dedicated Skolbarns hälsovanor tab, not
    one of the IND-shaped indicators — a single survey snapshot
    (2021-2022 as of writing), not a trend. Saves straight to
    data/processed/hbsc.json, no separate raw step.

pipeline/fetch_scb_population.py
    Downloads population by region, age band and sex from SCB (Statistics
    Sweden)'s BE0101A table — the denominator behind real age-
    standardisation for psych/antidep in js/data.js's standardRate().
    Not a mental-health measure. Saves straight to
    data/processed/scb_population.json, no separate raw step.

pipeline/fetch_policy_news.py
    Downloads policy and mental health news updates for real policy tracking.

data/ — FETCHED DATA
---------------------
data/raw/socialstyrelsen_mh_raw.json
data/raw/socialstyrelsen_psych_raw.json
data/processed/socialstyrelsen_mh.json
data/processed/socialstyrelsen_psych.json
data/processed/folkhalsodata_hlv.json
    The same data after being cleaned/reshaped into a simple common format
    (region, year, age group, sex, value, confidence bounds) — this is what
    build_kurvan_data.py reads to produce js/data/*.js.

data/processed/forsakringskassan_f43.json
data/processed/kolada_context.json
data/processed/hbsc.json
data/processed/scb_population.json
    Written directly by their fetchers (no separate data/raw/ step, unlike
    the three above) — sickness absence, the two Sammanhang context
    layers, HBSC, and the SCB population denominator respectively. Also
    read by build_kurvan_data.py.

.git/
    Git's own internal folder (version history) — not part of the app.
